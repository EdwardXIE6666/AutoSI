AutoSI

Windows 射频 SI 自动化：原理图 → 网络表 → SIwave S 参数 → ADS → 维修手册。

区 A 使用 侧栏六步，每步写出什么。 区 B 流程 各功能怎么走、描边为产物。 区 C 工作区 INPUT / OUTPUT 目录。
区 A · 使用

六步与产物

六步与产物
号 名称 写出
1 网络频段信息 OUTPUT/NETS 网络表，OUTPUT/OTHER 路径 PDF
2 初始化 SIwave 更新 INPUT/*.siw（叠层 / ODB，不抽 S 参数）
3 SIwave 抽取 OUTPUT/SPARAM PCB .sNp
4 ADS 仿真 OUTPUT/ADS
5 refnum 手册 路径预览 + *_refnum.xlsx
6 器件 Pin 路径 OUTPUT/OTHER/*_Device_Pin_Path.txt

打开 程序\MAIN.exe，侧栏 1–6 即上表。工作区是 FG*/INPUT 与 OUTPUT。

区 B · 流程

各功能怎么走

描边为该步写出的文件。功能 1、4、5、6 共用前半段（剖析与追径）。

共用前半段 01 网络表 02 初始化 03 抽取 04 ADS 05 手册 06 Pin
区 C · 工作区

INPUT / OUTPUT

工作区目录
目录 功能 内容
输入
INPUT — 原理图、SIwave 工程、叠层等
输出
OUTPUT/NETS 1 网络表
OUTPUT/SPARAM 3 PCB S 参数
OUTPUT/ADS 4 ADS 工程
OUTPUT/refnum 5 路径预览与手册 Excel
OUTPUT/OTHER 1 / 6 路径 PDF、器件 Pin 路径
OUTPUT/LOG 1–6 各功能运行日志

每个项目一个 FG* 文件夹，里面是 INPUT 和 OUTPUT。
