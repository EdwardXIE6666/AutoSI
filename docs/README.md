# AutoSI

Windows 射频 SI 自动化：原理图 → 网络表 → SIwave S 参数 → ADS → 维修手册。

侧栏六步、各功能流程、工作区目录见 [AutoSI架构.html](AutoSI架构.html)（浏览器打开，可打印 PDF）。

## 前提

目标电脑已安装与开发机相同版本的 **ADS 2025 Update1** 和 **SIwave**。

## 拷贝

把整个发布文件夹拷到目标电脑（路径尽量不要有奇怪字符）。用户能看见的只有：

| 内容 | 说明 |
|---|---|
| `MAIN.exe` | 主程序 |
| `配置环境.bat` | 一键配环境（只需跑一次） |
| `自动化仿真操作指导.docx` | 操作说明 |
| `_internal\` | 程序自己用的文件，不用打开 |

S 参数库、板材库不在安装包里，见下方。工作区由程序界面创建。

## 配置环境（只需一次）

1. 双击 **`配置环境.bat`**，UAC 点「是」；
2. 工具会检查 ADS / SIwave，缺的就装 Python、pywin32、Graphviz；
3. 最后一张表全是 `[ OK ]` 即可。有失败按说明处理后再跑一遍。

## 日常使用

1. 双击 `MAIN.exe`；
2. 欢迎页之后先**新建或打开一个工作区**（一个项目一个文件夹）；
3. 用界面把原理图 / ODB / `.siw` 加进该工作区的「输入」；
4. 再按功能 1 → 2 → 3 → 4 → 5 → 6 跑。结果在该工作区的「输出」里。

功能 3 完成后按界面琥珀色提示，在 ADS 的 Tools > AEL Command Line 粘贴命令。

## S 参数库和板材库

两只库都不随包。请到部门平台下载官方 S 参数库，板材库放到约定目录。查找顺序：`D:\` → `C:\Project` → 程序目录。目录名 `S参数库` / `板材库`（旧名 `2_S参数库` / `0_板材库` 也能找到）。

S 参数库请勿自行改文件。程序会校验完整性，被改过会拒绝运行。要增补请联系开发者更新官方库。

## 常见问题

- **功能 2 报找不到 python**：配完环境后重新打开 MAIN.exe；仍不行就重启电脑。
- **PDF 路径图没有生成**：Graphviz 没装好，再跑一次配置工具。
- **ADS 里宏报错**：确认最近一次功能 3 已生成 `fix_snp_auto.ael`（在 `_internal`）。
- **提示 S 参数库完整性失败**：从部门平台重新下载官方库覆盖。
- **找不到原理图**：先建工作区，再用「添加…」导入。
